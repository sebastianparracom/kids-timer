# Kids Timer

Sitio de una sola página listo para Vercel.

```bash
npm install
npm run dev
npm run build
```

En Vercel elige el preset **Vite**. El build genera `dist`.

## Archivos de personajes y videos

Reemplaza los placeholders cuando los tengas. El sitio busca primero `.png`, luego `.jpg` / `.webp`, y si no hay foto usa el SVG de ejemplo.

### Fotos

- `public/characters/sonic.png`
- `public/characters/amy.png`

### Videos (sin audio)

- `public/videos/sonic/loop.mp4`
- `public/videos/sonic/win.mp4`
- `public/videos/sonic/lose.mp4`
- `public/videos/amy/loop.mp4`
- `public/videos/amy/win.mp4`
- `public/videos/amy/lose.mp4`

También acepta `.webm` con el mismo nombre si el `.mp4` no está.
